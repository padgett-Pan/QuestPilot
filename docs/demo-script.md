# QuestPilot 省赛演示视频稿（录制版）

**目标时长：** 7 分 30 秒（符合 5–8 分钟要求）  
**语言与画面：** 普通话讲解，桌面端录制，1080p 及以上；建议导出中文字幕。  
**场景：** 本地 DemoProvider 演示；若配置真实文本模型，在计划生成段展示实时调用并准确说明模型名称。  
**边界：** 资料问答是自建的词法片段检索（非 embedding），评审分数由项目状态计算或模型打分；音视频转写与视觉分析仍是本地样例。录制时展示来源标签，不称词法检索为向量 RAG，也不称样例为真实转写或视觉推理。

## 录制前准备

- 开场自报家门使用真实报名信息：黑龙江职业学院第二校区 · C 组 · 团队 SIHP；成员潘庆涛、李嘉鹏、付松洋；指导教师冯玉雷、张兴华。
- 使用干净浏览器配置或无痕窗口；关闭通知、书签栏、开发者工具和错误覆盖层。
- 启动 `pnpm dev`，确认 `http://localhost:3000` 可访问。
- 学生账号：`student@questpilot.local` / `demo-student-password`；教师账号：`teacher@questpilot.local` / `demo-teacher-password`。
- 若配置真实模型，API key 只放 `.env.local`，画面不要展示密钥或管理后台凭证。
- 准备自制 TXT/Markdown 资料和经授权的短音频/视频，不使用个人信息或未授权素材。
- 录制窗口建议 1920×1080；成片需 5–8 分钟、普通话清晰、字幕同步。

**旁白：** “工作区通过登录保护。这里展示当前计划、任务进度、作品准备度、团队成员和资料条目。为了让录制过程可重复，当前视频使用本地演示数据，不包含真实学生隐私。”

### 01:35–02:20｜工作台任务闭环

**画面：** 展示任务列表、阶段、进度、评分准备度和团队面板，点击打开画布。  
**旁白：** “工作台呈现团队最近要推进的事项。任务会关联阶段、负责人、优先级和进度；右侧准备度按比赛维度展示状态。演示分数用于呈现界面效果，不是官方评审分数，也不代表真实项目得分。”

### 02:20–03:30｜AI 计划生成

**画面：** 计划画布触发重新规划，展示阶段任务与风险；Demo 模式说明 fallback 来源，Live 模式准确说出模型配置。  
**旁白：** “团队可以输入目标、队伍和技能。配置 OpenAI 兼容文本模型时，服务端生成结构化计划，再由 schema 校验阶段、任务、负责人、优先级和风险；模型未配置、输出不合规或请求失败时，系统回退到演示计划，并在界面上写明是哪一种来源。这里展示的是从自然语言目标到计划任务的核心 AI 交互。”

### 03:30–04:20｜资料空间与依据

**画面：** 打开知识库，上传 TXT/Markdown，展示资料条目；连问两个不同问题，对比命中片段的变化。  
**旁白：** “知识空间把上传的资料按段落切成片段，每个片段记录在原文中的字符位置。提问时系统用 TF-IDF 加余弦相似度做片段级检索，这里可以看到命中片段的标题、序号、相似度分数——换一个问题，命中的片段和分数都会变。当前用的是词法检索，还没有接入 embedding 语义召回；网页正文抓取和 PDF 解析也在下一阶段。”

### 04:20–05:20｜多模态作品评审入口

**画面：** 打开作品评审，上传自制短媒体文件，运行一次评审，展开分数证据。  
**旁白：** “评审页的分数不是写死的：它由当前项目的任务进度、资料片段数、媒体任务完成数和团队反馈计算，或者由模型按六个维度打分，每个分数都能看到它依据什么。上传的音视频会真实保存到本地目录并推进任务状态；但转写和关键帧分析还没有接入，所以报告里会明确标注为样例，不会伪造转写文本。”

### 05:20–06:05｜团队协作与教师批注
